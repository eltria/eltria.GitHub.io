03 — Core Engine
Agent 编排循环
核心 Agentic Loop 负责多轮对话和工具调用编排，最多执行 10 轮推理-执行循环。

Fig 2. Agent loop — multi-turn tool-use orchestration with streaming callbacks

Streaming Callbacks

Agent 在推理过程中通过三个回调实时通知通道层：OnText 传递增量文本，OnToolCall 通知工具调用开始，OnToolResult 返回工具执行结果。Matrix 通道利用这些回调实现流式消息编辑。

type RunOptions struct { Model string SystemPrompt string Parts []adapter.Part OnText func(string) OnToolCall func(name, args string) OnToolResult func(name, result string) }
